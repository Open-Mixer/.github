# The PLUGINS release unit: the ONE declaration of its members (the release-units design of 2026-11-24,
# section 2). The pipeline (.github/workflows/release-unit.yml) and
# the release tool (unit-release.sh) read it; no tool keeps a second list.
#
# One member per line, in build order: the repository (Open-Mixer/<repo>), then key=value fields.
#   level=N        dependency level: a member builds after every member of a lower level, beside the members of
#                  its own level. A member's level is one above the highest level of the members its packaging
#                  builds on (BuildRequires, Build-Depends). Two edges point back down and are taken from the
#                  channel at their floor: plugin-hostd-protocol's plugin-db-contract and plugin-hostd's
#                  libplugin-qualification-db-devel (section 9, fallback 2, removes them).
#   rpm=SRC deb=SRC  the source package of each format; '-' builds none of that format.
#   rpm-bins=, deb-bins=  the binaries the build must produce, comma separated; empty is the source name.
#   rpm-arches=, deb-arches=  comma separated; empty is build-rpm.yml's / build-deb.yml's default.
#   channel-deps=false  takes no BuildRequires from the channel.     needs-mod-host=true  builds mod-host first (rpm).
#   deb-deps=  build-deb.yml's dependencies input, comma separated.  build-packages=  extra distribution packages.
#   bootstrap=REPO:PACKAGE  a -contract package of member REPO, built at that member's commit of this run and
#                  installed for this member's build only (the omx-clap-contract step: omx-clap-contract, then
#                  plugin-hostd-protocol, then the rest of omx-clap-core).
#   reship=SHA     (set by unit-release.sh, never by hand) the member's last testing commit, re-shipped because its
#                  devel is red (section 5.1).
